# DBX 数据库管理（飞牛 fnOS 原生版）

一站式数据库管理工具，支持 **90+ 种数据库**：MySQL / MariaDB / PostgreSQL / SQLite / Redis /
MongoDB / ClickHouse / SQL Server / Oracle / DuckDB / Elasticsearch / Cassandra / Neo4j /
Hive / OceanBase / 达梦 / 人大金仓 …… 内建 SQL 编辑器、数据网格、表结构对比、数据导入导出与 AI 助手。

本版本为**飞牛 fnOS 原生打包**：一个全静态二进制 + 前端资源，**不需要 Docker**，
数据与配置全部保存在应用自己的数据目录内。

## 主要功能

- 多库连接管理：一次配好，随处切换；连接/密码保存在本机应用目录
- SQL 编辑器：语法高亮、补全、多语句执行、结果集分页与导出（CSV/JSON/Excel…）
- 数据网格：像表格软件一样编辑、筛选、排序，支持批量改值
- 表结构设计 / 对比：改字段、加索引、生成变更 SQL
- Redis / MongoDB / 消息队列等非关系库的专用浏览与命令台
- AI 助手（可选，需要自己配置模型服务；不配置也完全可用）

## 安装

在飞牛的 **FnDepot** 里添加本源的 `fnpack.json` 地址，然后安装「DBX 数据库管理」；
或从本仓库 Release 下载 `dbx_<版本>_x86.fpk`，在应用中心手动安装。

## 使用

1. 安装后飞牛桌面会出现图标，点开即用
2. **第一次打开会让你设置一个登录密码**（保存在本机应用数据目录里，不会上传任何地方）
3. 默认端口 **4224**；如需修改：应用中心 → 本应用 → 设置 → 服务端口 → 重启应用
4. 其他设备也能用浏览器访问 `http://<NAS_IP>:4224`，用上面那个密码登录

## 数据与卸载

- 数据目录：`/volN/@appdata/dbx/`（连接配置、查询历史、登录密码都在这里）
- 升级：卸载时**保留数据**，重装后连接和密码都还在
- 卸载：选择是否同时删除数据（向导里可选）

## 权限说明

应用以**专用低权用户**运行（不是 root），只读写自己的应用目录；不访问系统目录、不收集任何信息。
